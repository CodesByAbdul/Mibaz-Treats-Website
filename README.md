# Mibaz Treats & Events

A static, WhatsApp-first Next.js website for Mibaz Treats & Events. Update contact details and the Ramadan campaign switch in `src/config/business.ts` (or provide `NEXT_PUBLIC_WHATSAPP_NUMBER` and `NEXT_PUBLIC_BUSINESS_EMAIL`). Product and Iftar data live in `src/data`.

## Run

```bash
npm install
npm run dev
```
